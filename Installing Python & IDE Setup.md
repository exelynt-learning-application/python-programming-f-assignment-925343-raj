# Installing Python & IDE Setup

## 1. Introduction

Python is a high-level, general-purpose programming language widely used for web development, data science, artificial intelligence, and automation.

The objective of this assignment is to install Python, configure an Integrated Development Environment (IDE), and successfully execute a Python program.

## 2. Objectives

- Download and install the latest stable version of Python.
- Verify the Python installation using the terminal.
- Install and configure Visual Studio Code.
- Configure the Python interpreter.
- Create and execute a simple Python program.
- Provide screenshots as proof of successful setup.

## 3. Python Installation

**Step 1:** Visit the official Python website.

https://www.python.org/downloads/

**Step 2:** Download the latest stable Python 3 version suitable for the operating system.

**Step 3:** Run the installer and follow the installation instructions.

**Step 4:** Complete the installation and open Command Prompt.

## 4. Verify Python Installation

Open Command Prompt and execute:

```bash
python --version
```

The terminal should display the installed Python version.

**Installed Python Version:** [Enter your actual Python version]

**Screenshot:**

![Python Version Verification](screenshots/01-python-version.png)

## 5. Installing Visual Studio Code

**Step 1:** Visit the official Visual Studio Code website.

https://code.visualstudio.com/

**Step 2:** Download and install Visual Studio Code.

**Step 3:** Open VS Code and navigate to the Extensions section.

**Step 4:** Search for "Python" and install the extension provided by Microsoft.

## 6. Configuring the Python Interpreter

1. Open Visual Studio Code.
2. Press `Ctrl + Shift + P`.
3. Search for `Python: Select Interpreter`.
4. Select the installed Python 3 interpreter.
5. Confirm that the Python environment is selected.

**Screenshot:**

![VS Code Python Interpreter](screenshots/02-vscode-interpreter.png)

## 7. Creating and Running a Python Program

Create a new Python file named `hello.py`.

Add the following code:

```python
print("Hello, Python!")
print("Python environment setup completed successfully!")
```

Open the VS Code terminal and execute:

```bash
python hello.py
```

**Expected Output:**

```text
Hello, Python!
Python environment setup completed successfully!
```

**Screenshot:**

![Python Program Execution](screenshots/03-python-output.png)
